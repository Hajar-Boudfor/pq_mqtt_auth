# pq_mqtt_auth

Two implementations of post-quantum authentication for MQTT 5.0, based on the scheme of Samandari and Gritti.

- `kem_auth/`: KEM-based authentication (ML-KEM-512).
- `sig_auth/`: signature-based authentication (ML-DSA-44).

Each folder contains its own README with installation instructions.

## Reference

J. Samandari and C. Gritti, "Post-Quantum Authentication in the MQTT Protocol", *Journal of Cybersecurity and Privacy*, vol. 3, no. 3, 2023. doi:10.3390/jcp3030021
